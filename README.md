# 🛒 E-Commerce Platform (Frontend)

A modern, responsive React frontend for an e-commerce platform built with **React**, **Context API**, and **Tailwind CSS**. Features real-time state synchronization for user wishlists, dynamic profile avatar management, and secure JWT auth integration.

🚀 **Live Demo**: [https://ck-ecommerce-frontend.vercel.app](https://ck-ecommerce-frontend.vercel.app)  
🔗 **Backend Repo**: [ck-ecommerce-backend](https://github.com/MrChengKang/ck-ecommerce-backend)

---

## ✨ Key Features
- **User Authentication**: Login/Register with JWT token persistent storage and route protection.
- **Wishlist Management**: Real-time wishlist state updates using React Context API & `localStorage` synchronization across reloads (F5).
- **Profile & Media Upload**: Seamless image uploading for user profile avatars with status alerts.
- **Responsive Design**: Clean UI supporting seamless user experience on both desktop and mobile devices.

---

## 🛠️ Tech Stack
- **Framework/Library**: React.js, Vite
- **State Management**: React Context API
- **Styling**: CSS3 / Tailwind CSS
- **Deployment**: Vercel
